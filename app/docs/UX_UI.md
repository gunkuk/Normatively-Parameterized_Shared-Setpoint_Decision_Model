# Operator experience

Desktop-first responsive console: Overview, Elicitation, Policies, Buildings/Zones, Operation, Data ingest, Analytics, Research/Quality, Settings/Roles. Visible mode badges distinguish DEMO/SIMULATED and ACTUAL workflows. Scientific assumptions and detailed source snapshots are expandable rather than hidden.

A/B presentation begins with the synthetic-group scenario and uses mean and worst-person absolute temperature differences in Celsius. Expanding anonymous individual utilities reveals paired graphs and equality; clicking a person reveals source sex, study-age and desired temperature. Left/right is randomized by logged seed and maps back to internal A/B. The Overview explains outputs, prerequisites, all six operating steps and mode differences, with direct question and explicitly approved demo shortcuts. Times New Roman and locally bundled Noto Sans KR are the only configured font families.

Posterior chart uses compact q coordinates; credible-set components are explicit. Strict conflict diagnostics are separate. Contextual cells show UNIDENTIFIED instead of a fabricated estimate; fixed regret runs alongside contextual review with provisional warnings. Human approval precedes action recording; UI never claims equipment actuation.

Native labels, keyboard-operable controls, visible focus, responsive layouts and semantic tables support accessibility. WCAG 2.2 AA is a design target, not a completed independent conformance audit. Playwright screenshot evidence is in ../validation/.


## Publication panels

Question and result each have a Figure view: an isolated white panel, maximum 1,120 CSS pixels wide, with navigation/session controls outside the capture region. Escape or the return button exits; keyboard focus stays inside the active panel. The same live data and response actions are retained. Display A/B denotes left/right order and is not a new internal response encoding.

Questions retain scenario context and temperature-difference definitions. A/B labels and solid/hatched utility bars support non-color identification. Results show posterior cell probability mass (not epsilon probability density), explicit transformed q=epsilon/(1+epsilon) coordinates, median and disconnected credible-set intervals. Requested and attained mass are distinguished. No-response summaries show the prior and UNIDENTIFIED, not a personal epsilon estimate. Contextual results label the common distribution as comparison-only.

To capture: open Question Figure view or Result Figure view, choose the desired expansion state, and crop the white panel excluding the toolbar. Screenshots in validation/FIGURE_QUESTION.png and FIGURE_RESULT.png are browser-generated at 2x scale (2,240 pixels wide, sufficient for approximately 190 mm at 300 pixels/inch). The result screenshot uses one automated test response solely to demonstrate the interface; it is not a participant result or scientific finding. A publication caption must identify the actual session/sample and model assumptions. No English translation or journal-specific layout is implied.
