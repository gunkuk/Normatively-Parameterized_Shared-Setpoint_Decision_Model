# Operator experience

Desktop-first responsive console: Overview, Elicitation, Policies, Buildings/Zones, Operation, Data ingest, Analytics, Research/Quality, Settings/Roles. Visible mode badges distinguish DEMO/SIMULATED and ACTUAL workflows. Scientific assumptions and detailed source snapshots are expandable rather than hidden.

A/B presentation begins with the synthetic-group scenario and uses mean and worst-person absolute temperature differences in Celsius. Expanding anonymous individual utilities reveals paired graphs and equality; clicking a person reveals source sex, study-age and desired temperature. Left/right is randomized by logged seed and maps back to internal A/B. The Overview explains outputs, prerequisites, all six operating steps and mode differences, with direct question and explicitly approved demo shortcuts. Times New Roman and locally bundled Noto Sans KR are the only configured font families.

Posterior chart uses compact q coordinates; credible-set components are explicit. Strict conflict diagnostics are separate. Contextual cells show UNIDENTIFIED instead of a fabricated estimate; fixed regret runs alongside contextual review with provisional warnings. Human approval precedes action recording; UI never claims equipment actuation.

Native labels, keyboard-operable controls, visible focus, responsive layouts and semantic tables support accessibility. WCAG 2.2 AA is a design target, not a completed independent conformance audit. Playwright screenshot evidence is in ../validation/.
